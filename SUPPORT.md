# Support Codex Quota Bar

Codex Quota Bar is distributed as a donation-supported utility. If it helps you plan quota usage or avoid missing a reset window, you can support continued maintenance in three ways:

1. Star the GitHub repository.
2. Share the project with other Codex users.
3. Use the **Sponsor** button shown near the top of the repository when sponsorship is available.

Sponsorship helps cover macOS compatibility work, testing across quota-rule changes, and maintenance of reset activity monitoring.

Thank you for supporting independent software.
